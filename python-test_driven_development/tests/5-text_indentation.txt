The ``text_indentation`` function formats text around punctuation.

    >>> text_indentation = __import__('5-text_indentation').text_indentation
    >>> text_indentation("Hello. How are you?")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    >>> text_indentation(12)
